# בוט דילים של tustus – הרצה חינמית ב-GitHub Actions

הבוט בודק את https://www.tustus.co.il/Arkia/Home בערך כל 10–14 דקות (עם השהיה רנדומלית), ושולח לטלגרם צילום מסך והודעה קצרה (יעד, תאריכים ומחיר) רק כשעולה דיל שלא הופיע קודם.

## התקנה (פעם אחת, כ-5 דקות)

1. **ליצור ריפו ציבורי** ב-GitHub (New repository → Public). ריפו ציבורי מקבל דקות הרצה ללא הגבלה. הטוקן לא נחשף, כי הוא נשמר כ-Secret.
2. **להעלות את הקבצים**: `check_deals.py`, `requirements.txt`. 
   את קובץ ה-workflow יוצרים דרך **Add file → Create new file**, נותנים לו את השם `.github/workflows/deals.yml` ומדביקים את התוכן.
3. **להוסיף Secrets**: Settings → Secrets and variables → Actions → New repository secret
   - `TELEGRAM_BOT_TOKEN`: הטוקן של הבוט
   - `TELEGRAM_CHAT_ID`: ה-Chat ID שלך
4. **הרצת בדיקה**: לשונית Actions → tustus deals → Run workflow. ההרצה הראשונה רק לומדת אילו דילים כבר קיימים ולא שולחת כלום. התראות יגיעו רק על דילים חדשים.

## פקודת סטטוס
שולחים לבוט בטלגרם **סטטוס** (או `/status`). בהרצה הבאה, תוך 10–15 דקות לכל היותר, יגיעו:
צילום של ראש העמוד, רשימה קצרה של כל הדילים שבאתר כרגע, וצילום של העמוד המלא כקובץ.

## איך הבוט יודע מה חדש
כל דיל מזוהה לפי הכותרת שלו (יעד ותאריכים) יחד עם המחיר. לכן גם ירידת מחיר נחשבת דיל חדש.
הרשימה נשמרת בקובץ `state/seen.json` בריפו, והבוט מעדכן אותו בעצמו.

## הערות
- GitHub לפעמים מאחר בהרצות מתוזמנות בכמה דקות. זה נורמלי.
- כשאין דילים חדשים, או כשהאתר ריק, לא נשלח כלום. אפשר לראות כל הרצה בלשונית Actions.
- כדי לעצור את הבוט: Actions → tustus deals → ⋯ → Disable workflow.
